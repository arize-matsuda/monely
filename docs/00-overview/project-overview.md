最終更新: 2026-11-07

**このドキュメントは Monely を理解するための入口。** 新しく参加する人（および AI エージェント）は、まずこれを読んでから各設計文書に進む。

---

## 1. 一行で言うと

> スマホで数秒で記録できて、家族と同じ家計簿を見られる、自作の家計管理アプリ。

---

## 2. 背景

既存の家計簿アプリは「続かない」。原因は 3 つに整理できる。

1. **入力が面倒** — 起動から保存までのタップ数が多い。広告やレシート撮影の手間で習慣が途切れる。
2. **家族の支出が見えない** — 自分だけ記録しても、家族が払った分が入らなければ「わが家の今月」は分からない。
3. **機能が多すぎる** — 資産推移・ポイント・投資などで画面が埋まり、肝心の「記録する」が奥に沈む。

自分と家族が実際に続けられる最小限のものを自作する、というのがこのプロジェクトの出発点。

## 3. 目的

| | |
| --- | --- |
| **達成したいこと** | 家計の支出を記録する習慣が家族ぐるみで定着し、月末に「今月いくら使ったか」を即答できる状態 |
| **そのための手段** | 記録を 10 秒で終わらせる。世帯単位で 1 つの家計簿を共有する。それ以外の機能を作らない |
| **成功の判定** | ① 自分が 1 か月記録を続けられている ② 家族が説明なしで 1 件記録できる ③ 月末に合計を見るだけで支出を把握できる |

詳しい課題と提供価値 → [プロダクト要件](../01-requirements/product-requirements.md)

## 4. 対象ユーザー

| 役割 | 人物像 | 使い方 | 設計上の意味 |
| --- | --- | --- | --- |
| 本人（開発者） | スマホ中心。自分で作って自分で使う | 毎日の記録、月次の確認、設定、カテゴリ管理 | 多少の不便は自分で直せる。学習コストは問題にならない |
| 家族 | 技術に詳しくない。説明は最小限で済ませたい | 自分が払った分の記録、一覧の閲覧 | **ここが設計の制約。** パスワード管理を要求しない、初見で迷わない画面にする |

利用規模は **数人**（1 世帯）。一般公開するサービスにはしない。世帯への参加は招待コードが必要。

## 5. スコープ

### 5.1 v1（MVP）に入れる

| 分類 | 内容 |
| --- | --- |
| 認証 | メールアドレス + パスワード。パスワードを忘れたときはログインリンク |
| 世帯 | 作成、招待コードによる参加、世帯名の変更、メンバー一覧 |
| 収支の記録 | 支出・収入の登録／編集／削除（金額・日付・カテゴリ・支払者・メモ） |
| 一覧 | 月単位の一覧、日付ごとのグループ化、前月・翌月への移動 |
| 集計 | その月の支出合計・収入合計・差額 |
| カテゴリ | 初期カテゴリの自動投入、追加・改名・非表示 |
| 表示 | モバイルファースト、ダークモード対応 |

### 5.2 v1 に入れない（意図的に落とす）

| 落とすもの | 理由 |
| --- | --- |
| 予算設定とアラート | 記録が続く確証を得てから。v2 の第一候補 |
| 口座・資産の残高管理 | 記録の習慣化とは別の問題。設計も重くなる |
| グラフ・カテゴリ別の内訳 | 合計が見えれば v1 の目的は満たせる |
| CSV / レシート取り込み、銀行・カード連携 | 手入力が続くか確かめるのが先。連携は維持コストが高い |
| 定期支出の自動登録 | v2 |
| 複数通貨 | 日本円のみ。金額は整数（円）で持つ |
| 1 ユーザーの複数世帯所属 | v1 は 1 人 1 世帯。必要になったら中間テーブルを足す |
| プッシュ通知 | PWA 化のあと、必要になれば |
| 権限の分離（閲覧専用メンバー等） | 身内利用のため不要 |
| オフライン動作 | 通信前提とする |

### 5.3 将来も，やらないと決めたこと

- 一般公開のサービスにはしない（招待制を維持する）。
- 広告を入れない。

## 9. 原則

1. **続けられることが最優先。** 機能の多さではなく、入力の速さで価値が決まる。
2. **v1 に入れないものを守る。** 迷ったら落とす。落としたものはリストに残す。
3. **認可は `src/lib/data/` だけで行う。** ここを外すと最終防衛線が無い（[ADR-0005](../05-decisions/ADR-0005-authorization-in-app-layer.md)）。
4. **ドキュメントとコードを一緒に直す。** ずれた瞬間にこのドキュメント群の価値が消える。
